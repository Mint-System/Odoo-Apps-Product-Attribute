Setup EoS, EoL Announcment und EoL/S

- Install product_end_of_life_dates
- Open Inventry App
- Go to Products > Products Menu
- Open arbitrary product
- Check if fields "EoL Announcement", "EoS", "EoL/S" are visible
- Insert some dates in "EoL Announcement", "EoS", "EoL/S"

- Check if fields EoL Announcement, EoS, EoL/S are visible in list display
